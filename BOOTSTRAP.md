## What This Repo Is

`open-ippoc-main` is an IPPOC platform repository. It combines:

- `src/ippoc/soma`: identity/trust and body-side runtime components
- `src/ippoc/cortex`: cognition/orchestration components
- `src/kernel/openclaw`: OpenClaw gateway and control UI integration
