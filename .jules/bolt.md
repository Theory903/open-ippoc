## 2025-03-01 - Optimizing N+1 Graph Queries with CTEs
**Learning:** In the entity similarity search, fetching an entity's relationships individually inside a Python loop creates a massive N+1 bottleneck, scaling terribly with the number of entities in the database.
**Action:** When calculating set intersections across multiple rows in the database (like Jaccard similarity), push the computation down to the database using a Common Table Expression (CTE) combined with `COUNT(r.id)` and `GROUP BY`. This effectively executes the whole search in a single optimized SQL query, achieving ~22x speedup and removing repeated DB roundtrips.
