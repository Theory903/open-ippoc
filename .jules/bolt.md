## 2026-02-28 - [Graph Manager Jaccard Optimization]
**Learning:** In Mnemosyne's `graph/manager.py`, calculating Jaccard similarity between a target entity and all other entities by performing an N+1 query loop and Python-level set intersections leads to O(N * E) scaling, where N is total entities and E is their average edges.
**Action:** Replace the loop with a SQL CTE query that first filters candidates by joining target relations to the global relations table. Compute the Jaccard similarity `Intersection / (TotalA + TotalB - Intersection)` entirely in SQL and enforce a `HAVING` threshold to completely bypass unassociated entities. This reduced similarity search time for 1000 entities by ~100x (from ~1.01s to ~0.009s).
