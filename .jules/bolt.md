## 2023-10-10 - [SQL-based Cycle Pruning in Graph CTEs]
**Learning:** [An N+1 combinatorial explosion issue originally described in Python loop pathfinding logic had been refactored to a recursive CTE, but the cycle-pruning logic was omitted, retaining the core performance bottleneck. Using SQL strings for cycle checks inside the CTE recursive step effectively resolves it.]
**Action:** [When implementing optimizations from older issue descriptions, verify if the architecture has shifted (e.g., Python to SQL) and apply the functional intent of the optimization to the new structure. Ensure string-based path tracking inside recursive CTEs uses proper delimiter wrapping (e.g., `,path,` not like `%,node,%`) to avoid false positives and prevent combinatorial cycle explosions.]
